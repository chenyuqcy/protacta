Use case: ui-mockup. Create one polished 1536x1024 landscape design presentation with three realistic iPhone interface screens side by side on a restrained neutral background. It is a future UI design concept for Protacta, an existing native 3D/AR hands-on learning app. Reference image 1 is the current home screen and reference image 2 is the current 3D player; redesign them substantially while retaining the app name, real gearmotor and educational turbofan subject matter and real controls. The current design was rejected as merely plain rather than premium. Aim for the art direction of an exceptionally crafted Apple first-party product experience: precise typography and spacing, premium object photography, subtle optical depth, immaculate control proportions, one strong focal point per screen. Premium restraint, materially rich, not empty white boxes or a generic dashboard. Screen 1: light oyster-white home with a small Protacta wordmark, only two quiet category controls; a large editorial hero showing a beautifully lit realistic turbofan engine at a three-quarter front view on a softly shaded graphite/titanium stage, with only the short title 'Jet engine' and a small circular arrow button. Below it, two smaller carefully composed object previews, a sculptural folded paper airplane and a gearmotor; fewer equally weighted cards, stronger hierarchy. Screen 2: immersive light platinum 3D studio, realistic gray gearmotor large and centered with soft directional light and a subtle grounding shadow. Close icon top left, small centered 'Gearmotor', AR pill top right. Tiny '1 / 5'. At the bottom one meticulously proportioned translucent floating control tray: 'Lift the lid' as the only instruction, progress line, previous/play/microphone/speaker icons and a compact 'Next' button. Screen 3: edge-to-edge camera-like image of an engine model placed on a tasteful actual wooden tabletop, a compact 3D return button and step indicator, one small native frosted control tray below. Use SF-like native sans-serif typography, crisp monochrome icons, cool white, graphite, titanium silver, extremely restrained muted teal. Actual model subjects should remain recognizable from the reference images. Refined asymmetric composition, optical alignment, expressive depth from lighting rather than decoration. Avoid long sentences, slogans, badges, KPI numbers, repeated tiny captions, all-caps labels, neon gradients, sci-fi HUDs, fake AI/chat features, flat SF-symbol tiles, heavy borders and excessive rounded boxes. This is a visual concept, not proof of implemented camera behavior.
