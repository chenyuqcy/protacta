## Repeated external blocker

All three engineering phases queried the device inventory. The saved JSON in
`output/first-fold/available-devices.json`, `output/full-course/devices.json` and
`output/validation-capture/devices.json` reports the paired iOS devices' tunnel
state as **unavailable**. Current state was queried again in this phase. These
are terminal inventory queries, not a live install or camera job to wait on.

The first two phases made software progress despite this condition. The current
phase repaired checker defects and completed the concrete local evidence tools.
Remaining required acceptance now needs an actual connected/unlocked device,
physical paper handling/review, independent human annotations and beginner
participants. More simulated frames cannot establish those requirements.

## Shortest next gate

Connect and unlock an iPhone, enable its development access and resume the goal.
Build/install the Debug prototype, verify its real camera path, print the A4
sheet and review the complete physical sequence. Use the explicit local capture
tool and independent labeling process for actual accuracy/timing. Then calibrate
or change the implementation based on observed errors, review help content and
perform the beginner comparison. Keep the MVP incomplete until those gates pass.
